# The Last Trial

## Game Description

**The Last Trial** is a 2D survival game created using the **iGraphics** library in C/C++. The player must survive three levels of deadly challenges and finally destroy the system to escape.

## Features
- Memory challenge where the player races against two AI bots.
- Collapsing glass bridge with random red tiles.
- Health system with collectable energy bars.
- Doll detection: moving while the doll watches ends the game.
- Obstacle course with rocks, tree branches, a boat ride, and hidden hints.
- PIN puzzle, guard fight, and mask man boss fight.
- Background music and sound effects.

## Project Details
IDE: Visual Studio 2013

Language: C, C++

Platform: Windows PC

Genre: 2D survival

## How to Run the Project

Make sure you have the following installed:
- **Visual Studio 2013**
- **iGraphics Library** (included in this repository)

Open the project in Visual Studio
- Go to File → Open → Project/Solution.
- Select the .sln file from the cloned repository.
- Click Build → Build Solution.
- Run the program by clicking Debug → Start Without Debugging.

## How to Play

| Level | Objective | Controls | Game Over |
|-------|-----------|----------|-----------|
| **Level 1: Memory Challenge** | Memorize the safe tiles within 50 seconds and step only on safe tiles. The two players with the most safe tiles win. | Mouse Click to choose a tile | Stepping on a red tile |
| **Level 2: Collapsing Bridge** | Cross the glass bridge before it collapses and collect energy bars to keep health up. | `→` Move Forward, `↑` Jump, `C` Collect Energy Bar | Falling from the bridge or losing all health |
| **Level 3: System Destruction** | Escape the waiting room, cross the jungle and river, collect hints, enter the correct PIN, defeat the guard and the mask man, and upload the USB. | `→` Move Forward / Cross River, `↑` Jump, `Space` Fight | Moving while the doll watches, wrong PIN, or losing all health |
